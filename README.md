# Aura Music Signature V10 — GitHub Pages

Corrección de la barra Liquid Glass y del borde de portada.

## Correcciones
- La barra Liquid Glass ahora se oculta mientras está abierta la pantalla completa **Ahora suena**.
- La barra vuelve a mostrarse en Inicio, Biblioteca y Ajustes cuando hay una canción activa.
- Se eliminó el borde/contorno rojizo de la portada principal.
- Se mantiene la barra Liquid Glass, sus controles 3D azules y sus accesos rápidos.
- Caché PWA renovada para que GitHub Pages cargue esta versión.

## Publicar la actualización
1. Descomprime el ZIP.
2. Sube todos los archivos directamente a la raíz del mismo repositorio GitHub Pages.
3. Reemplaza los archivos existentes y confirma los cambios en `main`.
4. Abre Aura Music con conexión a internet para que cargue la nueva caché.
5. Si aún ves la versión anterior, cierra completamente la PWA y vuelve a abrirla.

Conserva el mismo repositorio/dominio y no borres los datos del sitio para mantener la biblioteca local.
